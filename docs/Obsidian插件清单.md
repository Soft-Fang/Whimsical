## 手动安装步骤

1. 在 Obsidian 里打开你的 vault（本项目建议直接把仓库目录当 vault）
2. `设置` → `第三方插件` → 关闭「受限模式」(Restricted mode)
3. 点「浏览」(Browse)，按下面表格的 **搜索关键词** 逐个搜索
4. 核对 **插件 ID** 一致后点 `安装` → `启用`

> 插件名容易撞车。最稳的是点开「官方页面」链接，确认作者和插件 ID 都对得上再装。

## 新电脑上需要重新配置的

下面这些**故意不进仓库**（含密钥或机器专属路径），换电脑后手动重设一次：

| 插件 | 要重设什么 | 为什么没跟着走 |
|---|---|---|
| Git | GitHub 用户名 + Personal Access Token | Token 存在 `data.json` 里，提交等于泄密 |
| Templater | 模板文件夹路径 | 绝对路径每台电脑不一样 |
| 其他带登录态的插件 | 各自的账号 / API Key | 同上 |

> 具体位置：`.obsidian/plugins/*/data.json`。本项目的 `.gitignore` 已把它们全部排除。
