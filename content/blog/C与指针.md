# 第6章 指针

## 内存和地址

位（1，0）->字节（8个位）->字（4个字节）

一个字只有一个地址，一般是最左或最右的字节位置，根据不同机器规定

  * 内存中的每个位置由一个独一无二的地址标识
  * 内存中的每个位置都包含一个值

高级语言一般都是利用名字而不是地址来访问内存位置，这些名字也就是我们所称的变量，利用名字来访问内存位置是编译器来实现的，而不是硬件提供的，硬件依然是通过地址来访问内存位置。

## 值和类型

一个变量在内存中储存的值，不一定与其声明时相同，其取决于使用的方式。如果使用的时整数算数指令，这个值就会被解释为整数，如果使用的时浮点型指令，它就是浮点数。 —-不能简单地通过检查一个值的位来判断它的类型。必须观察程序中这个值的使用方式。

## 指针变量的内容

指针的初始化是用&操作符完成的，它用于产生操作数的内存地址。

## 间接访问操作符

通过一个指针访问它所指向的地址的过程称为 **间接访问** 或 **解引用指针 **。

## 未初始化和非法的指针

```c
int *a;
*a=12;//错误
//由于a没有被初始化，不知道指向哪，无法预测12会被储存到哪。可能会导致无意修改内存中重要地址的值
//在对指针进行间接访问前，必须确保其初始化。
```

## NULL指针

NULL是一种特殊的指针变量，表示不指向任何东西。故不能对其进行解引用（间接访问）。

要使一个指针变量为NULL，可以给它赋值为0； 测试一个指针变量是否为NULL，可以与0进行比较。

对所有指针变量进行显式的初始化是种办法，如果已经知道指针将被初始化为什么地址，就把它初始化为该地址，否则就初始化为NULL。

## 指针，间接访问和左值

**左值** –必须标识一个特定的位置

**右值** –必须指定一个值

指针变量能作为左值，不是因为它们是指针，而是因为它们是变量。

间接访问指定了一个特定的内存位置，这样我们可能把间接访问表达式的结果作为左值使用。

```c
int a;
int *d=&a;
*d = 10 - *d; //包含了两个间接访问操作：右边的间接访问作为右值使用，所以它的值是d所指向的位置所储存的值(a的值)。
			  //左边的间接访问直接作为左值使用，所以d所指向的位置a把赋值符右侧的表达式的计算结果作为它的新值。
d = 10 - *d;  //第二条语句是非法的，左侧为指针，右侧为整型值
```

## 指针，间接访问和变量

*&a=25 <==> a=25

*&a==> *(&a)

&操作符产生变量a的地址，它是一个指针常量。

*操作符访问其他操作数所表示的地址，操作数是a的地址，所以把值25储存在a中

## 指针常量

```c
*100 = 25; //错误
*(int *)100 = 25; //正确 强制类型转换此时的100就是对应的内存位置

//此方法只有在需要访问特定内存位置时才需要使用
```

## 指针表达式

```c
char ch = 'a';
char *cp = &ch;

/*
ch      左值：表示ch的存储位置，给ch赋值
		右值：表示ch中存放的值 'a'

&ch	 	左值：非法 未标识出一个特定位置
		右值：ch的地址

cp		左值：cp的储存位置，给cp赋值
		右值：cp的值  ==> ch的地址

&cp		左值：非法  与&ch类似
		右值：指针变量cp的地址

*cp	 	左值：ch的地址
		右值：ch的值 'a'
---------------------------------------------
* 操作符的优先级高于 +

*cp+1	左值：非法  先引用cp中的值，再+1  此时是值运算 未标识出特定位置
		右值：ch的值+1  'a'+1='b'  * 运算符优先于 +

*(cp+1) 左值：先进行cp+1 将cp中的地址（ch）向后移动一位 即特定标识为ch的下个地址 给其赋值
		右值：紧随ch后的地址中的值
---------------------------------------------
++操作符的优先级高于 * 采取右结合

++cp	左值：非法  先进行++操作 使cp指向ch的下个地址；再返回cp的值一个拷贝 但未标识出该拷贝的去向
		右值：先++  使得cp指向ch的下个地址；再返回cp的值（ch的下个地址）

cp++	左值: 非法  先返回cp值的一个拷贝；再++使cp指向ch的下个地址  但未标识出该拷贝的去向
		右值：返回cp的值后，cp再增值

*++cp	左值：ch下个地址  先进行前缀++操作 先使cp指向ch的下个地址 再返回cp中的值
			            再利用 * 标识左值为上述操作返回得到的cp所指的ch的下个地址位置
		右值：ch下个地址的值

*cp++	左值：ch的地址    先进行后缀++操作 先返回’cp中的值 再使cp指向ch的下个地址
			            再利用 * 标识左值为上述操作返回得到的cp所指的ch的地址位置
		右值：ch的值 ，cp指向ch下个地址
---------------------------------------------
++ 与 * 都是右结合
++*cp	左值：非法   先执行*cp 得到ch的地址  再执行++  使cp所指的地址值+1  再返回这个值的拷贝
				   但未标识出该拷贝的去向
		右值：ch的值+1  'a'+1='b'  得到ch值的拷贝

(*cp)++	左值：非法   先执行*cp 得到ch的地址  再执行++  先返回cp所指地址的拷贝  再将cp所指的地址值+1
				   但未标识出该拷贝的去向
		右值：先得到ch值的拷贝（a）  ch的值再+1  'a'+1='b'

++*++cp	左值：非法   先执行++cp 将cp所指的地址+1后返回该值  再对该值进行间接访问也就是访问ch的下个地址位置
				   再将该地址位置中的值+1后  返回该值的拷贝   但未标识出该拷贝的去向
		右值：cp指向ch的下个地址，返回ch的下个地址的值+1

++*cp++	左值：非法   先执行cp++ 将cp所指的地址返回后 再+1  在对该返回值进行间接访问也就是访问ch地址位置
				   再将该位置中的值+1后 返回该值的拷贝   但未标识出该拷贝的去向
		右值：先利用cp返回ch的地址，cp再指向ch的下个地址，再利用刚才返回的ch地址的值+1
*/
```

## 指针运算

指针算法并不依赖于指针的类型。

当一个指针和一个整数量指向算数运算时，整数在执行加法运算前始终会根据合适的大小进行调整。

调整：把整数值和“合适的大小”相乘 float指针+3 ==>实际上加到指针上的整型值为12 也就是向后移动了3个float的大小

### 算术运算

#### 指针 +/- 整数

数组中的元素出差呢于连续的内存位置中，对指针进行加减就是将指针指向的位置在数组内移动，但是如果所指的位置在数组第一个元素的前面或在最后一个元素的后面，那么其效果就未定义。

将其指向最后一个元素的后面是合法的，但是对其进行间接访问可能会失败

#### 指针 - 指针

当两个指针都指向同一个数组中的元素时，才允许从一个指针减去另一个指针。

```c
float a[20];
float *p,*q;
p=&a[5],q=&a[10];
p-q=-5   //结果不是 -5*4  运算结果与数据类型无关
```

当两个指针指向不同数组中的元素时，它们相减的结果就是未定义的。

### 关系运算

< <= > >=

通过比较可以判断出在同一个数组内的两个指针，哪个指针更靠前。

对于指向不同数组内元素的指针，只能判断两者是否相等，而不能判断大小。

允许 **指向数组元素的指针** 与 **指向数组最后一个元素后面的那个内存位置的指针** 进行比较

但不允许与**指向数组第一个元素前面的那个内存位置的指针** 进行比较

## 警告总结

  1. 错误地对一个未初始化的指针变量进行解引用
  2. 错误地对一个NULL指针进行解引用
  3. 向函数错误的传递NULL指针
  4. 未检测到指针表达式的错误，从而导致不可预料的结果
  5. 对一个指针进行减法运算，使它非法地指向了数组第一个元素的前面的内存位置

## 编程提示总结

  1. 一个值一个只具有一种意思
  2. 如果指针并不指向任何有意义的东西，就把它设置为NULL

# 第13章 高级指针话题

## 进一步探讨指向指针的指针

```c
int i;
int *p;
int **pp;
i=1;
pp=&p;
//p=&i; == *pp=&i
//**pp == *p == i
```

增加 * 的个数就是增加间接访问的层次，层次越高，需要使用的次数就越少

## 高级声明

```c
int (*f)();      //函数指针，由于第一个括号的存在，使 f 先指向某个函数，这个函数的返回值为int
int *(*f)();	// ------------------------------------------------这个函数的返回值为int类型的指针
int *f[];		//f是数组，数组元素为int类型的指针
int f[]();		//非法，f[]这个数组中的元素为函数，但由于数组中的元素长度应该相同，不同函数的长度又不一定相同
int f()[];		//非法，f()为一个函数，其返回值为数组，但由于函数只能返回标量值，不能返回数组
int (*f[])();	//合法，*f[]是个数组，数组的元素为函数指针，函数返回值为int类型
```

## 函数指针

函数指针在使用前，与其他类型指针一样需要进行初始化。

```c
int f( int );
int (*p)( int ) = f;
				= &f;//此处的&可有可无

int a;
a = f(20);
a = (*p)(20);
a = p(20);
```

  * 当编译器调用函数时，会**将函数名转化为一个函数指针** 。也就是说，f 作为函数的函数名，在调用时也会被编译器转化为一个函数指针，调用其指向的函数地址。
  * 这也就是为什么 & 可有可无，其作用只是将这一转化过程显性的标识出来。
  * 下述三条函数调用语句等效，第三条更清晰的表明了对于函数指针调用函数来说，**间接访问并不是必需的** ，因为编译器本身会将函数名转化为函数指针，整个函数调用过程，**必需的就是一个函数指针** 。

### 回调函数

```c
Node *search_list(Node *node,void const *value,int (*compare)(void const *,void const *))
    //const 将变量定义为常变量，即其变量值不会再被赋予新值
    //int (*compare)(void const *,void const *)  compare是函数指针，其指向的函数返回值为int类型
    //为了处理不同类型的数据，直接将其传入数据定义为一个指向未知类型的指针 void *
{
    while(node != NULL)
    {
        if(compare(&node->value,value)==0)      //通过比较返回值，使得数据的比较与其类型无关
        {
            break;
        }
        node = node->lnik;
    }
    return node;
}

int compare_int(void *a,void *b)  //当需要比较的是两个int类型数据时，函数指针compare可指向此函数、
    							  //传入的a,b为指向未知类型的指针
{
    if(*(int *)a == *(int *)b)    //将a,b强制类型转化为指向int类型的指针，并进行间接访问
        return 0;
    else
        return 1;
}

int compare_double(void *a,void *b)//当需要比较的是两个double类型数据时，函数指针compare可指向此函数、
    							  //传入的a,b为指向未知类型的指针
{
    if(*(double *)a == *(double *)b) //将a,b强制类型转化为指向double类型的指针，并进行间接访问
        return 0;
    else
        return 1;
}

//对于字符串的比较，若不使用如上述两种的自定义函数进行比较，而是使用库函数strcmp，则可能会报错，因为此函数的传入数据类型不能为void，而得是明确的char类型
```

**当遇到不同类型的数据需要相同的处理时，可以利用这一技巧。**

### 转移表

转换表 <==> 函数指针数组

例定义：

```c
double (*oper_func[])(double,double) = {add,sub,mul,div}；//函数指针数组
result = oper_func[ oper ](op1,op2); //根据oper的不同值（1，2，3） 访问上述数组中的不同函数
```

在使用函数指针数组时要注意 [ ] 内的数据不能过大，超出范围。否则会转移到一个未知的地址，执行未知的指令，导致很多问题，甚至难以检测。

## 命令行参数

main函数中一般有两个参数：argc（命令行的数目）,argv（作为指向指针的指针，指向这组参数值的第一个元素）

```c
int main(int argc,char **argv)
{
}
```

  * 命令行都是以字符串的类型存在，这一组参数值可以被视为一个数组，argv就指向这个数组的第一个元素，这个数组末尾以NULL结束。
  * 这组参数值的第一个参数，就是这个程序的名称。

```c
#include <stdio.h>
int main(int argc, char ** argv)
{
    int i;
    printf("%d\n",argc);
    for (i=0; i < argc; i++)
        printf("%s.\n", i, argv[i]);

    return 0;
}
/*结果：
1
C:\Users\司淮\Desktop\文件名.exe.
*/
```

**处理命令行参数** （在cmd中执行）

prog -a -b -c name1 name2 name3

第一个为文件名，后续零个或多个带有 ’ - ‘ 的字母表示多个选项，用于对文件以某种方式进行处理，若没有文件则对标准输入进行处理。

```c
while(*++argv != NULL && **argv == '-')
    //对argv指向的地址进行间接访问，判断其是否为空（是否到达命令行的末尾）
    //访问argv指向的命令行（字符串）中的第一个元素，判断是否以'-'开头，
{
    switch(*++*argv){    //根据右结合性先执行++*argv，使*argv指向其命令行（字符串）中的第二个元素，再进行间接访问
        case 'a':
            option_a = TRUE;
            break;
        case 'b':
            option_b = TRUE;
            break;
    }
}
//经过以上判断处理后，再利用自定义的函数，对文件进行操作。
```

## 字符串常量

当一个字符串常量出现在表达式中时，它的值是个指针常量。编译器会将这些字符储存在内存的某个位置，并储存一个指向第一个字符的指针。

当数组名用于表达式中时，它们的值也是指针常量。

  * “xyz”+1

表达式结尾是个指针，指向字符串第二个字符：y

由于“xyz”这个字符串常量本事实际上是个指针，故+1相当于指针指向下一个值。

```c
#include<stdio.h>
int main()
{
	char t;
	t=*("xyz"+1);
	printf("%c",t);
 }
```

  * *“xyz”

由于“xyz”作为字符串常量，其实际上是个指向字符的指针，指向第一个字符也就是 ‘x’ 。此处就是进行间接访问 ‘x’

  * “xyz”[2]

相当于访问字符串数组的第3个字符

  * *(“xyz” + 2)

类比利用指针访问数组中的第3个字符

  * 将一个整型数据转换成十六进制，并输出个位数：putchar(“0123456789ABCDEF”[value%16]);
