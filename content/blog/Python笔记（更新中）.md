### 从列表中添加元素

  * **append()** 添加元素

格式：列表名.append(要添加的元素) 一次只能添加一个参数（元素）

  * **extend()** 拓展列表（用列表扩展列表）

格式：列表名.extend(要添加的列表) 一次只能添加一个参数（列表）

  * **insert**()可控制元素添加的位置，上述方法默认添加再列表最后

格式：列表名.insert(位置,元素) 位置从0开始

### 从列表中获取元素

​ 格式：t=列表名[元素位置]

### 从列表中删除元素

  * **remove()**

格式：列表名.remove(要删除的元素内容)

  * **del** 非函数而是一个语句

格式：del 要删除的内容 （可以是元素也可以是整个列表）

  * **pop** ()

格式：列表名.pop(元素位置） （元素位置为空时 默认为最后一个元素）

### 列表分片

实现一次性获取列表中的多个元素

格式：列表名(起始位置：结束位置)

最后会得到从（起始位置）到（结束位置-1）范围内的所有元素

```python
a = [11,12,13,14,15,16]
a[1:3] = [12,13]
a[:3] = [11,12,13]
a[1:] = [12,13,14,15,16]
a[:] = [11,12,13,14,15,16]
```

**注意！！**

b = a 和 b = a[:] 的区别

### 列表函数

  1. **从列表中查询元素出现次数**

函数：count()

格式：列表名.count(元素)

最后会得到查询元素在列表中出现的次数

  2. **从列中查询元素出现的位置**

函数：index()

格式：列表名.index(元素,查询范围起始位置,结束位置)

最后会得到查询元素在范围内的所有出现位置

  3. **将列表整个反转**

函数：reverse()

格式：列表名.reverse()

最后列表会前后反转 [1,2,3] ==>[3,2,1]

  4. **用指定的方法将列表排序**

函数：sort()

格式：

列表名.sort() （默认参数reverse=False）

最后列表内元素会由小到大排序

列表名.sort(reverse=True)

最后列表内元素会有大到小排序

**注意：T F大写**

## 再论字符串

  * 串名(a) = capitalize() 将字符串第一个字符改为大写
  * 串名(a) = casefold() 将字符串全改为小写

上述两个函数都是返回的一个全新字符串，不改变原字符串(a)

  * 串名(a) = center(width)

将字符串剧中，并使用空格填充至长度为width的新字符串

  * 串名 = count(sub[,start[,end]])

返回sub在字符串中出现的次数，start和end参数表示查找范围

  * 串名 = endswith(sub[,start[,end]])

检查字符串是否以sub字符串结束，如果是则返回Ture,否则返回False

  * 串名 = expandtabs(tabzise=8)

把字符串中的tab符号(\t)转化为空格，空格从非空格的第一个数开始算起。tabzise默认为8，可改

  * 串名.find(sub[,start[,end]]) r-(从右边开始)

用于检测sub是否包含在字符串中 不存在则返回-1

  * 串名.index(sub[,start[,end]]) r-(从右边开始)

与find的相同 但是不存在时会产生一个异常

  * 串名:join(sub)

以字符串作为分隔符，插入到sub中所有字符之间

  * 串名:replace(old,new[,count])

替换久的字符串，count控制替换次数

  * 串名:spilt(sep=None,maxsplit=-1) spiltlines(([keepends]))

自动切片

### turtle(画图)

```python
from turtle import *
color('red','red') #控制线条颜色，控制填充颜色
begin_fill()
for i in range(5): #for循环 in range循环五次
    fd(200) #右转角度
    rt(144) #左转角度
end_fill()

turtle.setup(宽，高，横坐标，纵坐标) #启动窗口的参数，控制turtle 的起始位置
turtle.penup() #提起画笔
turtle.fd(移动距离) #直线移动
turtle.pendown() #放下画笔
turtle.pensize() #运动轨迹的宽度
turtle.pencolor() #运动轨迹的颜色
turtle.seth() #启动时运动的方向
turtle.circle(半径，弧度，做圆内多边形的边数) #以给定半径画圆
turtle.done() #结束绘画
turtle.bk() #反向
turtle.seth(45) #旋转绝对角度45°
```
