## 数据类型

### 符号常量

```c
#define PRICE 30
```

用标识符代表一个常量 成为符号常量

**#define** 编写在程序开头（预处理过程） 意思是程序进行预处理把后面的PRICE当作常量30

_#define M 10 称为宏（预处理） 表示将以下程序中所有出现的M的意义改为10_

下面程序中出现的PRICE全都当作30进行计算

**八进制** 整常数 _以0开头作为前缀_

**十六进制** 整常数 _以0X或0x作为前缀_
123456789abcdef按顺序表示1~15

**补充** ：内存中的二进制存储
一个字节byte=8位bit

数值是以**补码** 表示的：

正数的补码:_原码相同_
负数的补码： _将该位数绝对值的二进制形式按位取反再加1_

**例** ：求-10的补码
10的源码：00001010
取反：11110101
再加1，得-10的补码：11110110

  * int（整型）4字节

  * long（长整型）4字节

  * short（短整型）2字节

  * unsigned（无符号整型）4字节

  * 单精度浮点类型4字节

  * 双精度浮点类型8字节

头文件<stdint.h> 定义了 int16_t 、 uint32_t 、 int64_t 等整型，在需要确定大小的整型时可以使用它们代替 short 、 unsigned long long 等，在 C 整型中，只使用 int 。

头文件<inttypes.h>添加了一些宏定义，PRIi8、PRIu8、PRIo8以及PRIx8，其中i为有符号，u为无符号，o为8进制以及x为16进制。

```c
//在包含有inttypes.h头文件的程序中，
int32_t a;
printf("a = %" PRId32 "\n", a);
//函数中，PRId32被定义在inttypes.h中的"d"替换，故该句等价于
printf("a = % " "d" " \n",a);
//C语言中多个连续字符串组合成一个字符串，因此，该句又等价于
printf("a= %d\n", a);
```

**例** ：2.1E5（等于2.1*10^5）

## 数组

### 数组的定义与使用方式

**数组 是具有相同类型的数据的有序集合**
数组中每个数据称：1.数组元素 2.下表变量
 _C语言中使用数组必须先定义_

**定义方式** ： 类型说明符 数组名[常量表达式]
**例** ：int a [10]; 表示定义了一个整型数组，数组名为a，此数组有10个整型变量元素

  * 数组下标**永远是从0开始** 的 上述10个元素便为0~9，而没有10
  * 数组的大小不能在运行时依赖变量定义
  * 数组大小不等于0 要用[ ]
  * int a[10]; 表示定义数组长度为10
t=a[6]; 表示引用序号为6的元素（从0开始） 即t=7

_这样部分赋值 后五个元素的值都会是0_

## 函数

### 认识函数

**由主函数调用其他函数，其他函数也会互相调用。同一个函数可以被一个或多个函数调用任意多次**

_函数的两类_ ：

1.无参数函数 void printstar( ) void表示没有返回值 （ ）里为空表示没有参数

2.有参数函数

#### 无参函数的定义形式

类型标识符 函数名（ ）
{
声明部分
语句部分
}

#### 有参函数的定义形式

类型标识符 函数名（形式参数表列 ）
{
声明部分
语句部分
}

**例** ：

```c
int max(int x,int y)
{
       int z;
       z=x>y?x:y;
       return(z);
}
```

```c
//z=x>y?x:y;等价于 ↓
if(x>y)
    z=x;
else
    z=y;
```

### 形式参数和实际参数

  * 在有参函数小括号内的变量称为 **形参**
  * 在主调函数小括号中的变量成为 **实参**
**返回值用return（ ）返回**

不同函数之间传递数据，可以使用的方法：

  * 参数：通过形式参数与实际参数
  * 返回值：用return语句返回计算结果
  * 全局变量：外部变量
  * 形参与实参类型相同或赋值兼容
  * 形参不会影响实参
  * 被调用函数定义出现在主调函数前，可以不加声明

### 函数的嵌套调用

在定义一个函数时，其内又包含另外一个函数的完整定义。
C语言不能嵌套定义，但可以嵌套调用

#### 局部变量

在一个函数内部定义的变量是内部变量，它只在本函数范围内有效

#### 全局变量

**限制使用全局变量** ：

1.占据较多内存

2.降低程序清晰性

3.函数通用性降低

  * 在函数外定义的变量为全局（全程）变量
  * 全程变量可使用的范围为：其从其定义位置开始一下的所有语句都可使用
  * 主函数与定义函数内的同名变量意义不同，不会发生冲突

### 变量的存储类别

动态储存方式与静态储存方式：

通过变量值存在的时间（即生存期）进行变量区分。

  * **静态** 是指在程序开始时由系统分配固定存储空间

  * **动态** 是指在需要时再分配

C语言中每个变量与函数有两个属性：数据类型和数据储存类别

#### auto

auto（自动）变量为函数中的局部变量，属于动态存储方式

  * auto a <=>auto int a <=> int a
  * static a<=>static int a 默认为整型

#### static

用static声明 _局部变量_

  * **静态的** 局部变量：函数中的局部变量的值**在调用结束后不消失而保留原值**
  * 静态局部变量是在编译过程中赋初值的，**即只赋值一次** ，在**运行时已有初值**
  * 静态局部变量在函数**调用结束后仍然存在** ，但**其他函数不能引用它**

#### register变量

变量（静，动）是存放在**内存中** 的
**为提高效率** ，可以把局部变量的值通过用`register`声明后**放在CPU的寄存器**(寄存器数量有限)中，需要时可以直接取出，而不必到内存中存取 在寄存器中存取的效率更高

#### extern

**用于声明外部变量，以扩展外部变量的作用域 把函数中的变量定义为全局变量**

需要建立储存空间的声明称为定义性声明
不需要的称为引用性声明

  * 内部函数：在定义的函数前加上static 那么这个函数就不能被其他文件使用
  * 外部函数：在定义的函数前加上extern或什么也不加，则此函数可以被其他文件调用

## 指针

### 认识指针

内存区的每个字节有一个编号（地址）
直接访问如：a=6；
间接访问如：scanf(“%d”,&a);
**指针是一个特殊的变量，是用来存放地址的**

**例** ：
int * i_pointer *_此处的_ 意义不是取值操作符而是定义后述变量为指针**

可以通过 i_pointer=&i **可以认为输入值给 i 再把 i 的值放到该地址**

  * 知道了一个变量的地址，就可以通过这个地址来访问这个变量，因此， _把**该地址** 称为**该变量** 的“指针”_

  * C语言中可以定义一类特殊变量，专门用来存放变量的地址，称为指针变量

  * **注意！！！**
指针变量的值（即指针变量中存放的值）是地址（即指针）。

**指针是一个地址** ，而**指针变量是一个变量** 。

定义指针变量时**必须** 指定基类型

### & 与 *

*称为**取值** 操作符

& 称为**取址** 操作符

**例** ：
已经执行pointer=&a
那么&_poiner_1的含义？
&与 * 的*_优先级相同**，但按** 自右往左**的方向结合，故 **先** 进行*pointer_1的运算，即&*pointer_1<=>&a

```c
#include <stdio.h>
void splitfloat( float x, int *intpart, float *fracpart )
{
	*intpart = (int)x;
	*fracpart = x- (*intpart)；
}
int main()
{
    float x, fracpart;
    int intpart;
    scanf("%f", &x);
    splitfloat(x, &intpart, &fracpart);//将变量intpart, fracpart的地址转给自定义函数
    printf("The integer part is %d\n", intpart);
    printf("The fractional part is %g\n", fracpart);
    return 0;
}
```

## 数组与指针

  * 一个变量有地址，一个数组包含若干元素，每个数组元素都在内存中占用存储单元，它们都有相应的地址。
  * 指针变量可以指向变量，也可以指向数组元素
  * 数组元素的指针就是数组元素的地址

```c
int a[10];
int *p;
p =&a[3];
p=a;  //p地址指向数组a的地址
//p++ ==> p=&a[4]
//p=a  ==> p=&a[0]

f(int arr[ ],int n) <=> f(int *arr,int n)//用数组名作函数参数
```

**实参用数组名，形参用指针变量**

### 多维数组与指针

```c
int a[2][3]
a  //数组名，指向a[0]

a[0] == *a(a+0) == *a  //0行0列元素地址

a+1 == &a[1]  //1行首地址

*(a[1]+2) == *(*(a+1)+2) == a[1][2]  //1行2列元素a[1][0]的值
```
